CPU wants instructions, 
Main memory is empty.
CPU defers to load instructions
from the firmware chip on the motherboard
and begins executing instructions  ^i0GjrxxJ

Firmware code does a POST, 
initializes the remaining hardware,
detects the connected peripherals ^rkgitNq3

firmware code cycles through all storage devices,
looks for a boot-loader.
If found then firmware hands over control to the computer to it ^XO2uUXBG

the rest of the OS.
GRUB is one such boot-loader that is capable of loading 
UNIX-like OS.
Boot-loader is only available in the first sector of a disk, which is 512 bytes ^UtH2oBc5
