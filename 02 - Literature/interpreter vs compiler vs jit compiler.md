## Interpreter
```
Source Code -> Interpreter -> Intermediate Code.  
```

- Execute line by line
- Immediate execution
- Translation overhead during execution

## Compiler

- Translate whole source code into machine code before execution
- Faster run time performance
- Compilation can slow down initial development

```
Source Code -> Compiler -> Machine Code -> Run machine code
```


## JIT Compiler (Just In Time)

- Both interpreter and Compiler
- Compiling code after a program has begun 
- Many implementation of JIT compilation
- Start by interpreting code and then compile frequently
- Covers
	- Immediacy of interpretation
	- Performance benefits of compilation
