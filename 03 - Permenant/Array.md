# Array

Array is a fixed size buffer. 

**What happens when you want to increase the size of a traditional array?**
You must reallocate a new array, create a new larger array, and copy the contents of the old array into the new one

Arrays can have variable sizes (determined at runtime) or compile-time fixed sizes (where the size is a constant known before program execution)
