- ECMAScript is a standard for general-purpose scripting languages, defined by ECMA International in the document ECMA-262.
- Serves as the blueprint for various scripting langauges, Like JS

- **Standardization:**
    It is standardized by Technical Committee 39 (TC39) of Ecma International, ensuring interoperability and consistency across different implementations

- **Core Language Definition**
	- Defines the fundamental syntax, types, objects, and functions that a conforming scripting language must support
	- This includes elements like data types (boolean, number, string), control flow statements, object literal initialization, error handling mechanisms and built-it objects such as `JSON`, `Math` 

**ECMAScript defines what a scripting language should look like, while JavaScript is an actual implementation of that specification**
