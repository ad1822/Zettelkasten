# interpreted vs compiled vs vm

So, there are three types of langauges

1. interpreted like python, JS, php
2. complied like rust, c, c++, go
3. vm like java (jvm), c##

We already know, what's the difference between interpreted and compiled languages, but Instead of giving a direct `binary` file to run, VM gives a virtual machine to run that `binary` file like java

For compiled code, there is no runtime dependencies, So just build or compile a source code, and just deploy it. Most efficient way and faster that other
