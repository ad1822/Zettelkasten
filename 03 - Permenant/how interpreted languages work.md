- An interpreted language works through a program called an "interpreter" that directly executes instructions written in the programming lang. without first compiling the entire program into machine code
- There is no compiler in this process, where a compiler translates the entire source code into machine-executable code before runtime

- **Source Code Input:**
    The interpreter receives the program's source code, which is typically human-readable text.
- **Line-by-line execution :**
	Unlike a compiler that processes the entire program, an interpreter reads and processes the source code line by line, or in small chunks.
- **Translation and Execution:**
- For each line or chunk of code, the interpreter performs the following:
	- **Lexical Analysis (Scanning):** It breaks down the code into individual tokens (e.g., keywords, identifiers, operators).
	- **Syntactic Analysis (Parsing):** It checks if the sequence of tokens follows the language's grammatical rules, creating an internal representation (like an abstract syntax tree).
	- **Execution:** It then directly executes the corresponding operation or instruction based on the parsed structure.
