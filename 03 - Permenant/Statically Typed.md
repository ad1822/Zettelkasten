# Statically Typed

a programming language where the data types of variables are known and checked at `compile time` (before the program runs) rather than at `runtime` (while the program is running

```go
var num int = 40
var s string = 40 // This gives an error because it's a string
```

That means your editor and the compiler can display type errors before the code is ever run, making development easier and faster.
