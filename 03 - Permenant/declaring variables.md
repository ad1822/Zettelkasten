# declaring variables

There are two types for declaring variables

```go
var s string = "sjdkfjksdhnf" // Usr var and = for declaration

s := "sdjknfsjkldnf" // inferred to be a string
```

`:=` called a short assignment statement

For global assignment use `var`, there is not `:=` available

Also We can declare a multiple value in a single line like 

```go
s, i := "sdfks", 2323
```
