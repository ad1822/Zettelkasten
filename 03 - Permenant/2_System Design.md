# 2_System Design
## Horizontal Scaling
- Buy More Machine 
- Load Balancing Required
- **Resilient**
- Network Calls (Remote Procedure Calls) 
- Data Inconsistency
- **Scales well as USERS Increase**

### Vertical Scaling
- Buy Bigger Machine 
- No Requirement of Load Balancing
- Single Point of Failure
- **Inter Process Communication**
- **Consistent**
- Hardware limit
