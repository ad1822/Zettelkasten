# Boilerplate in html5

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My Web Page</title>
</head>
<body>

  <h1>Hello, world!</h1>

</body>
</html>
```

#### `<!DOCTYPE html>`
- Tells the browser this is an **HTML5 document**
- Prevents older “quirks mode” rendering

#### `<html lang="en">`
- Root element of the page
- `lang="en"` helps with **accessibility** and **SEO**

#### `<head>`
- Contains **metadata** (not visible on the page).

#### `<meta charset="UTF-8">`
- Sets character encoding
- Allows special characters (€, é, emojis 😄)

#### `<meta name="viewport" content="width=device-width, initial-scale=1.0">`
- Makes the page **responsive**
- Essential for mobile devices

#### `<title>`
- Text shown in the browser tab
- Used by search engines

#### `<body>`
- Contains **everything visible** on the page
- Text, images, buttons, forms, etc.
