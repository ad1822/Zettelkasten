# DynamoDB

- Fast and flexible NoSQL database service
- Virtually unlimited storage
- Items can have differing attributes
- Low latency queries
- Scalable read/write throughput

---

##### Core Components
- Tables, Items and attributes are the core components.
- Supports two different kinds of primary keys : Partition Key and Partition Sort key
