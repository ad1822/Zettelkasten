# S3

- Data is stored as objects in buckets
- Virtaully unlimited storage 
- Includes notification services

#### Amazon S3 offers a range of object-level storage classes that are designed for different use cases : 
1. Amazon S3 Standard
2. Amazon S3 Intelligent-Tiering
3. Standard-Infrequent Access (S3 Standard-IA)
4. One Zone-Infrequent Access(S3 One Zone-IA)
5. S3 Glacier
6. S3 Glacier Deep Archive


#### Common Scenarios
1. Backup and Storage
2. Application Hosting
3. Media Hosting
4. Software Delivery
