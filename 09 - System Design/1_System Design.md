# 1_System Design

- Optimise process and increase throughput -> Vertical Scaling
- Preprocessing beforehand during non-peak hour -> Preprocessing & CronJob
- Get more resources and Backups -> Resilient
- Keep backups and void single points of failure -> Backups
- Get More resources -> Horizontal Scaling
- Micro Service Architecture
- Distributed Systems (Partitioning)
- Load Distribution -> Balance Load between different systems/ server
- Decoupling 
- Logging and Metrics Calculation
- Extensible
